## 既有确定性回归检查

初次发布时运行 `python -m unittest discover -s tests -v`：10 项通过。本次仅替换案例截图与文档，不修改运行代码，没有重复执行同一组单元测试。

| 检查 | 验证方式 |
| --- | --- |
| 分享文字与 `modal_id` | 提取目标短链与作品 ID，排除无关数字 |
| 媒体主机名 | 允许实际 CDN，拒绝仿冒域名、非标准端口与认证信息 |
| 缺失 SSR 字段 | 返回无数据，不把缺失字段伪装成 -1 |
| 浏览器兜底 | 模拟 SSR 缺失后返回正确视频 |
| 明确不存在 | 不启动无意义的浏览器兜底 |
| 浏览器错误 | 保留可读的处理提示 |
| 清晰度 | 仅列出实际提供的分辨率与大小 |
| 详情响应过滤 | 只匹配目标主机、接口及作品 ID |
| 业务错误状态 | 解析失败使用 HTTP 502 |
| 分段媒体代理 | 传递 Range 与 HTTP 206、Content-Range、正确字节 |

同时通过 `python -m py_compile app.py browser_parser.py`。先前修复验证也通过前端脚本语法检查。

这些单元测试使用模拟响应，不代表已访问大量真实作品。

## 历史兼容性与端到端验证

在用户提供的单条公开视频上，已完成：

- 解析短链接并匹配正确作品 ID、标题、作者与 27 秒取整时长。
- 分享页缺少数据时，通过桌面 Edge 获得作品详情。
- 返回 `2160p`、`1440p`、`1080p`、`720p`、`576p` 五档实际地址。
- 默认地址及两档高清地址的分段请求返回 HTTP 206、`video/mp4`、`Content-Range` 和 MP4 文件头。
- 前端显示结果，视频 `readyState` 达到 4。
- 前次完整端到端测试中，一档下载完成，下载错误为空，页面脚本错误列表为空。
- 初次发布时确认五档结果与视频 `readyState: 4`，保存实际首页和结果卡片截图；其中旧结果图现已替换为上面的 AI 产品宣传片案例。
